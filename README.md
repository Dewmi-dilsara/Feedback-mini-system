# Feedback Management System

## Overview

This project implements a feedback system that allows users to submit ratings using a public feedback link.

Features include:

- Dynamic feedback form configuration
- Rating submission (1–5 scale)
- Expired feedback handling
- Already responded detection
- Validation handling
- REST API integration
- Frontend UI using Next.js
- Unit and controller tests

---

## Tech Stack

### Backend
- Kotlin
- Spring Boot
- MongoDB

### Frontend
- Next.js
- TypeScript

### Testing
- JUnit 5
- Mockito
